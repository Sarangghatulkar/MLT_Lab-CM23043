How overlay works: A hidden <video> element captures the webcam feed. Each frame is drawn to a <canvas> using drawImage(). MobileNet classifies the frame every 500 ms and results are drawn on top of the canvas using fillText() with a semi-transparent background box. The video canvas and the inference run independently so the feed stays smooth.
